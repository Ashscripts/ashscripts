The Scene

Thursday morning. Ashpak has the Windows compliance policies running. The dashboard shows 84% compliance across Windows devices; the remaining 16% are getting email notifications and have 3 days to fix issues before being blocked. He turns to macOS. 150 MacBooks. Zero compliance policies. He already knows from the security audit that: 23 have the firewall disabled 41 have Gatekeeper set to allow unsigned apps 12 have SSH enabled Unknown number have FileVault disabled The configuration profiles from Lesson 4.5 will push the correct settings. But configuration profiles don't verify the device is actually in the correct state. That's compliance policies.

"Configuration profiles push settings. Compliance policies verify them. Both are necessary." He opens the macOS compliance policy blade.

macOS Recovery and running csrutil disable. A user doing this is a significant security event

; they're either a developer testing something or actively bypassing security controls. Making

SIP a compliance requirement means any Mac with SIP disabled is immediately flagged and blocked. Device Properties Tab

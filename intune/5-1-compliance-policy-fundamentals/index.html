The Scene

Wednesday morning. Riya drops a printed report on Ashpak's desk. It's the quarterly security audit.

"Page 7," she says, and walks away. Ashpak turns to page 7: Finding 3.2; Device Compliance GapOf 847 enrolled devices, 23% have not confirmed BitLocker encryption status. 14% are running OS versions below the organisation's stated minimum. 8% have not reported antivirus status in 30+ days. The organisation has no automated mechanism to block non-compliant devices from accessing corporate resources. Ashpak reads it twice. The devices are enrolled. Configuration profiles are deployed. But Intune has no way to judge whether a device meets AshScript's security standards; and no automated way to act when it doesn't. He opens a new browser tab. "Compliance policies. Today."

What Is a Compliance Policy?

A compliance policy is a set of rules that defines the minimum security requirements a device must meet. Intune evaluates each device against these rules and assigns it a compliance state.

COMPLIANCE POLICY CONCEPT
COMPLIANCE POLICY defines

Compliance + Conditional Access: The Power Pair

Grace Periods: The Human Element

Compliance policies have a critical setting: the grace period. This is the number of days a device can be non-compliant before Intune marks it as non-compliant and Conditional Access potentially blocks it.

COMPLIANCE POLICY STRUCTURE
PART 1PLATFORM
Which OS? Windows / macOS / iOS / Android
PART 2COMPLIANCE RULES
The actual security requirements
(OS version, encryption, password, AV, etc.)
PART 3ACTIONS FOR NON-COMPLIANCE
What happens when device fails?
• Send email to user (immediately)
• Mark as non-compliant (after grace period)
• Retire device (after extended period)
• Push notification to device
PART 4ASSIGNMENTS
Who does this policy apply to?
Assign to users or device groups

1 GRACE PERIOD LOGIC 2 ────────────────────────────────────────────────────── 3 Device fails a compliance check │

Why grace periods matter: Without a grace period, a device that reboots and hasn't

checked in yet could be instantly blocked from corporate resources. Grace periods give devices time to check in and report compliance; and give users time to fix legitimate issues before being locked out.

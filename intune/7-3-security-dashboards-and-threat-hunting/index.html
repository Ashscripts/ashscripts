Advanced Hunting; KQL Queries Advanced Hunting is MDE's query engine. It queries 30 days of raw telemetry from every onboarded device using Kusto Query Language (KQL).

Key Tables Available:

Hunt 1; Finding Encoded PowerShell (Obfuscation)

1 // Find all encoded PowerShell executions 2 // Encoded commands are a common attack technique 3 // Legitimate PowerShell rarely uses -EncodedCommand 4 5 DeviceProcessEvents 6 | where Timestamp > ago(7d) 7 | where FileName == "powershell.exe" 8 or FileName == "pwsh.exe" 9 | where ProcessCommandLine has_any 10 ("-enc", "-EncodedCommand", "-ec") 11 | project 12 Timestamp, 13 DeviceName, 14 AccountName, 15 ProcessCommandLine, 16 InitiatingProcessFileName 17 | order by Timestamp desc

Results at AshScript:

Hunt 2; Lateral Movement Detection

1 // Find devices making SMB connections to 2 // other internal devices (lateral movement pattern) 3 // Legitimate SMB is expected between specific pairs 4 // Unusual SMB = potential spread attempt 5 6 DeviceNetworkEvents 7 | where Timestamp > ago(7d) 8 | where RemotePort == 445 // SMB 9 | where RemoteIPType == "Private" // Internal only 10 | where ActionType == "ConnectionSuccess" 11 | summarize 12 TargetDevices = dcount(RemoteIP), 13 Connections = count() 14 by DeviceName, bin(Timestamp, 1h) 15 | where TargetDevices > 3 // Connecting to 3+ devices 16 // in same hour = suspicious 17 | order by TargetDevices desc

Results:

Hunt 3; Persistence Mechanisms

1 // Find new scheduled tasks created in last 7 days 2 // Focus on tasks created by non-system processes 3 // Malware commonly uses scheduled tasks for persistence 4 5 DeviceProcessEvents 6 | where Timestamp > ago(7d) 7 | where FileName == "schtasks.exe" 8 | where ProcessCommandLine has "/create" 9 | where InitiatingProcessFileName !in 10 ("msiexec.exe", "setup.exe", 11 "install.exe", "TrustedInstaller.exe") 12 | project 13 Timestamp, 14 DeviceName, 15 AccountName, 16 ProcessCommandLine, 17 InitiatingProcessFileName 18 | order by Timestamp desc

Results:

Hunt 4; Data Exfiltration via DNS (DNS Tunnelling)

1 // DNS tunnelling: attackers encode data in DNS queries 2 // Signs: long subdomain names, high query frequency 3 // to unusual domains 4 5 DeviceNetworkEvents 6 | where Timestamp > ago(7d) 7 | where ActionType == "DnsQueryResponse" 8 | extend DomainLength = strlen(RemoteUrl) 9 | where DomainLength > 50 // Unusually long DNS query 10 | summarize 11 QueryCount = count(), 12 UniqueSubdomains = dcount(RemoteUrl) 13 by DeviceName, RemoteIP 14 | where QueryCount > 100 // Many queries to same IP 15 | order by QueryCount desc

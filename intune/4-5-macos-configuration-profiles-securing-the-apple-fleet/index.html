The Scene

Friday morning. Ashpak has just finished the Windows security profiles. He swivels his chair to face the second monitor; the one showing the macOS device list. 150 MacBooks. All enrolled. Zero configuration profiles beyond the enrollment profile. His phone rings. It's Priya from Design:

"Ashpak, I just got a notification saying my Mac needs a software update but it's asking me to restart during a client presentation. Can IT control when updates happen?"

Before he can answer, a message from the Dev team:

"Our MacBooks don't auto-connect to the corporate Wi-Fi anymore after the password changed. We have to manually rejoin every time."

Then an email from Security:

"Audit finding: 23 AshScript MacBooks have the firewall disabled. 41 have Gatekeeper disabled; allowing unsigned apps. 12 have remote login (SSH) enabled with no restriction."

Ashpak puts the phone down.

"150 MacBooks. Zero security configuration. Let's fix that." He opens the Intune portal and navigates to macOS configuration profiles. Today, he will build the complete macOS security and configuration stack; without breaking Priya's design tools, the developers' workflows, or the executives' seamless experience.

Profile 4: Privacy Controls (TCC Policy)

TCC (Transparency, Consent, and Control) is macOS's permission framework; it controls which apps can access camera, microphone, screen recording, contacts, etc. Without MDM, users get individual permission prompts for every app. With MDM, Ashpak pre- approves permissions for trusted corporate apps; no prompts, no confusion: 1 intune.microsoft.com

The Dev team at AshScript needs local admin rights to install development tools. Ashpak creates a scoped exception just for them:

Principle of least privilege: Standard users cannot install software or modify system

settings. This is the correct default. Only the Dev team gets admin rights; and even they are scoped. Priya in Design is a standard user. She cannot install unapproved apps. Her design tools (Adobe etc.) are deployed by IT via Intune.
